**  Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer**

The Standard Laptop Procurement Automation project is a ServiceNow solution designed to streamline the IT hardware procurement process using Flow Designer. 
The project automates the creation of a Catalog Task when a Standard Laptop request is approved and assigns the task to the Hardware team for configuration.
This automation eliminates the need for manual task creation and assignment, ensuring that approved laptop requests are processed consistently and efficiently. 
It improves task visibility, reduces delays, minimizes manual errors, and enables the hardware team to begin laptop configuration promptly.
The solution integrates the Service Catalog, Requested Items, Approvals, Flow Designer, and Catalog Tasks to create a simple end-to-end automated procurement workflow.
